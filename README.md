# f Store — мебель для жизни

Русскоязычный демонстрационный магазин с интерактивной комнатой, созданной в Blender.

**Сайт:** https://antony502189-max.github.io/furniture-store/  
**3D-комната:** https://antony502189-max.github.io/furniture-store/room.html

## Что работает

- 16 товаров с локальными фотографиями: категории, поиск с поддержкой ё/е, комнаты, материалы, цена, сортировка и страницы каталога.
- Карточки с вариантами цвета, избранное, корзина с количеством и пересчётом, профиль, сохранение и скачивание подборок.
- 3D-гостиная: вращение, масштабирование, прогулка с клавиатуры и экранных кнопок, выбор предметов, три палитры, дневное и вечернее освещение.
- Добавление отдельных предметов или выбранного комплекта из комнаты в корзину.
- Русские формы, валидация, черновик обращения, клавиатурная навигация и мобильное меню.
- Модель и Three.js находятся в репозитории: внешние CDN и сервер не нужны.

Цены, ассортимент и контакты вымышлены по запросу владельца. Это демонстрация: реальной оплаты, доставки, отправки заказов и сообщений нет. Данные сохраняются в localStorage на устройстве посетителя. Фотографии иллюстрируют каталог; Blender-модели — стилизованные интерпретации. Старые данные англоязычной версии остаются в прежних ключах; новая версия использует отдельное пространство `fstore-v2-*`, поскольку ассортимент, валюта и варианты изменились.

## Разработка

```sh
python3 scripts/build.py
python3 -m http.server 8123 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8123/. Генератор использует стандартную библиотеку Python. Источники: `scripts/build.py` (разметка), `products.json`, `app.js`, `styles.css`, `room.js`. Он создаёт пять HTML-страниц и `store.js`, в который включены данные каталога. Изменения скриптов и стилей получают новые хеши в URL для обновления кэша.

GitHub Pages обслуживает корень `main`. Сгенерированные страницы и `store.js` нужно коммитить; `.nojekyll` отключает Jekyll. Все ссылки и импорты относительные, поэтому сайт работает в `/furniture-store/`.

Модель можно пересоздать через Blender:

```sh
blender --background --python scripts/create-room.py -- assets/models/room.glb
```

Подробности модели — в `assets/models/README.md`. GLB содержит 5 выбираемых групп, 61 примитив и около 64 тыс. треугольников, занимает 2,6 МБ. При отсутствии WebGL или ошибке модели показываются превью и доступная подборка товаров.

## Проверки

```sh
python3 tests/check.py
node --test tests/store.test.cjs
npm install
npx playwright install chromium webkit
npm run test:e2e
```

`tests/check.py` проверяет русский язык, локальные ссылки, уникальность ID, разметку select, 16 товаров, импорты Three.js и структуру GLB. Unit-тесты проверяют повреждённое/запрещённое хранилище, неизвестные товары, количество, цвета, профиль, избранное и экранирование текста.

Playwright проверяет все товары, корзину, сохранение и скачивание подборок, поиск, фильтры, формы, мобильное меню, пять страниц на ширинах 360/390/768/1024/1440, 3D и отказ загрузки модели. Chromium проверяет WebGL; Linux WebKit — интерфейс и резервный режим. Тесты используют отдельные браузерные контексты. GitHub Actions запускает эти проверки и сохраняет отчёт.

Для проверки уже опубликованной версии:

```sh
BASE_URL=https://antony502189-max.github.io/furniture-store/ npm run test:e2e
```
