# 3D-комната

Оригинальный интерьер создан в Blender 4.5.10 из процедурной геометрии. Модель не использует сторонние модели, изображения или текстуры.

- `room.glb` — готовая сцена glTF 2.0, 2,6 МБ, 64 404 треугольника, 61 материал-меш (вместо 346 отдельных примитивов).
- `room-poster.webp` — рендер Blender для превью и режима без WebGL.
- Исходный генератор: `scripts/create-room.py`.

Повторный экспорт из корня репозитория:

```sh
blender --background --python scripts/create-room.py -- assets/models/room.glb
```

Дополнительный второй аргумент задаёт путь к PNG-превью; рядом сохраняется редактируемый `.blend`.

Единицы измерения — метры. Размер комнаты 6 × 5 м. Координаты Blender `(X,Y,Z)` становятся glTF `(X,Z,-Y)`: пол `y=0`, задняя стена `z=-2.55`, левая стена `x=-3.05`. Передняя и правая стены открыты для обзора.

Пустые родительские объекты `product-sofa`, `product-coffee-table`, `product-modern-armchair`, `product-nightstand`, `product-floor-lamp` содержат `extras.productId`. Все дочерние меши наследуют принадлежность к товару. Нужный идентификатор определяется подъёмом по `parent` после raycast. Остальная геометрия не является товаром.

Рекомендуемая камера общего вида: `[7,6,8]`, цель `[0,1,0]`. Старт прогулки: `[0,1.65,1.9]`, взгляд на `[0,1,-1.5]`. Свет и камера в GLB отсутствуют — их задаёт браузер.
