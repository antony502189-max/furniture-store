# Photography

Photographs downloaded from Unsplash, licensed under the [Unsplash License](https://unsplash.com/license). The exact original image URL for every bundled file is recorded in [sources.json](sources.json). Local WebP copies are resized and compressed for this storefront. No AI images were generated for this update.

These are illustrative stock photographs for the existing demo catalog and sample team, not photographs of verified store inventory or employees. Color controls save the selected demo variant; they do not recolor the photograph.
